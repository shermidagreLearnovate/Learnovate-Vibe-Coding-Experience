# Research Model Configuration

This project is a dedicated research environment to test and evaluate the capabilities of Gemini 2.0 (and future models) in a "vibe-coding" context.

## Research Goals
1. **Model Autonomy:** Evaluate how well the model handles end-to-end tasks from infrastructure to refactoring.
2. **Framework Fidelity:** Test knowledge of React (Vite), NestJS, Prisma, and Tailwind CSS.
3. **Surgical Precision:** Assess the ability to make targeted changes without side effects.
4. **UX/UI Intuition:** Evaluate "visual taste" and user empathy in frontend development.

## Project Phases
- **Phase 1: Infrastructure** (Monorepo setup, Prisma Schema, Docker)
- **Phase 2: Frontend** (Layout, Kanban Board, Types/Mocking)
- **Phase 3: Backend API** (CRUD, Logic, Frontend Integration)
- **Phase 4: Refactoring** (Feature additions, UX improvements)

## Active Strategy
- Prioritize React/NestJS/Prisma patterns.
- Maintain a monorepo structure.
- Focus on high-quality, idiomatic code and proactive UX suggestions.
